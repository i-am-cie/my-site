WebTech Lab

Web Technologies · semester project

Learning web technologies, one week at a time

This is the practice site I built during the course. It started as a single index.html and grew week by week: structure and semantics first, then external CSS, links and paths, images, a navigation that is written once and injected by JavaScript, and finally a couple of small interactions.

What I practised

The site follows the lessons in order. Every week added a page, a rule or an asset.

Semantic structure

Header, nav, main, section, figure and footer instead of a pile of generic boxes. Headings in order, one h1 per page.

External CSS

One stylesheet for the whole site, with custom properties, a shared container and a mobile breakpoint at 780 px.

Links and paths

Relative paths between pages and into img/, so the same files work locally and on GitHub Pages.

Images

A real hero image with empty alt as decoration, and every content image with meaningful alt text.

JavaScript and the DOM

A shared navigation, a random quote, a toy and a game — all plain DOM code, no libraries.

Git and GitHub Pages

Work committed step by step in a local repository, pushed to a public GitHub repository and published from the main branch.
