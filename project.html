Project ideas

Six things I could build next with what this course taught me. Each one is small enough to finish, and each one teaches something the others do not.

  1. 1 · Personal dashboard

    A start page that opens with the links I use every day: a clock, the weather for my city and a list of shortcuts. The interesting part is the layout — a grid that still looks right on a phone.

    HTML and CSS grid fetch a JSON API Difficulty: medium

  2. 2 · Recipe box

    Add recipes, tag them (breakfast, quick, vegetarian), filter the list and let the browser remember them after a reload. A gentle introduction to storing data on the client.

    DOM and events localStorage Difficulty: easy

  3. 3 · Study timer

    A 25-minute focus timer with breaks, a progress ring that fills up and a sound when time is over. Small, but it needs accurate timing and a lot of care around edge cases.

    setInterval SVG ring Difficulty: easy

  4. 4 · Quiz game

    Ten multiple-choice questions, one at a time, with a score and a review of the wrong answers at the end. Good practice in keeping state in one object and rendering from it.

    State handling conditional styling Difficulty: medium

  5. 5 · Pixel art editor

    A 16 × 16 grid where clicking a cell paints it, with a colour picker, an eraser and a button that exports the drawing as a PNG. The hardest of the six, and the most fun.

    canvas pointer events Difficulty: hard

  6. 6 · Weather card

    One card, one city: current temperature, a small forecast and an icon that changes with the weather. Mostly about handling a request that can fail, slowly or badly.

    async fetch error states Difficulty: medium
